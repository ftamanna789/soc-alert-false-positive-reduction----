## Concise CV version (SOC / Cyber Security Analyst)
**MSc Research Project — ML-Based SOC Alert False-Positive Reduction** | University of Hertfordshire

- Investigated network intrusion-detection alert quality using Python, Isolation Forest, Autoencoder and TabNet, focusing on SOC false-positive reduction and attack recall.
- Applied network-flow preprocessing, anomaly scoring, confusion-matrix analysis and threshold optimisation to compare alert-handling trade-offs.
- Reported 47.08% false-positive reduction for tuned Isolation Forest, 54.14% for Autoencoder compared with an Isolation Forest baseline, and 57.19% for threshold-tuned TabNet, with an attack-recall trade-off in TabNet.
- Documented experimental limitations, dataset provenance questions and requirements for reproducible evaluation.

**Project:** https://github.com/ftamanna789/soc-alert-false-positive-reduction----
